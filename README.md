# Круг поиска

Локальный статистический калькулятор распространённости заданного профиля среди 100 млн взрослых жителей России. Это не сервис знакомств и не прогноз вероятности встречи.

## Запуск

```bash
npm install
npm run dev
```

Тесты и production-сборка: `npm test`, `npm run build`.

## Модель и ограничения

Единственный источник коэффициентов — `population_model.json`. Калькулятор сначала разбивает население по полу и каждому году возраста, а затем применяет доступные условные распределения. Доход аппроксимируется логнормальным распределением по медиане и p90, рост — нормальным, вес — нормальным распределением BMI с пересчётом через средний для группы рост.

Файл не содержит совместных численных распределений для образования × дохода, занятости × дохода, семейного положения × детей, физических и визуальных признаков. Такие признаки считаются условно независимыми внутри пола и возраста. Это явное, детерминированное приближение, а не дополнительные выдуманные данные; при большом числе критериев точность ниже. Для улучшения модели нужны совместные таблицы этих признаков и статистика ковариации роста и веса.
